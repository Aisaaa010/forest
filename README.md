# 森间 · Forest & Stillness

使用 Vue 3 Composition API、`<script setup>` 单文件组件和 Vite 构建的纯前端森林放松空间。无后端，收藏数据保存在当前浏览器。

## 启动与构建

```sh
npm install
npm run dev
```

开发地址：http://127.0.0.1:5173 。Vue 单文件组件需要通过开发服务器运行。

```sh
npm run check
npm run build
npm run preview
```

`check` 检查 Vue 组件与 JavaScript 语法；`build` 输出静态网站至 `dist/`；`preview` 在 http://127.0.0.1:4173 预览生产构建。

## 功能

- 晨雾松林、雨落青苔、萤火之境、雪落松林、雪境木屋和极光冰原六种森林 / 冷岛场景，雪景使用独立风景图和飘雪效果。
- Three.js 低多边形松林、实例化 3D 雨雪、拖拽视角、树冠萤火与点击涟漪 / 飘雪互动；无 WebGL 时回退到 Canvas 效果。
- 独立冷色岛：欧洲雪境的主木屋、右侧小屋、火堆、冰湖、雪径、栅栏、烟囱与蓝调清晨 / 黄昏暖窗切换；南极冰原的架高科考小屋、连续冰川墙、冰瀑、冰柱与极光。
- 每个场景有独立相机预设、目标高度和环绕范围；冷色岛限制在正面视角，避免看到薄片边缘。
- 主木屋增加门框、窗棂、木柴堆、雪铲、基座石、屋檐雪块和雪地脚印；原木改为圆角胶囊截面，小屋和火堆也使用圆木与石圈。
- 轻触木屋窗户、小屋、火堆、极地小屋、冰川或极光会触发暖光、火光、冰体脉冲与粒子回应；单击只触发反应，双击或“探索细节”胶囊才进入聚焦。
- 聚焦视图提供可见的“返回全岛”、Esc 退出、目标名称、按物体包围球计算的镜头距离、补光与更紧的阴影视锥。
- 支持右键 / 双指平移、滚轮朝光标缩放；聚焦时降低雾密度并提高环境反射，静止后再提升一档像素比。
- 六种场景共用程序化天空穹顶，但每个主题有独立色板、云层、太阳/月晕和星空：晨雾暖灰、雨幕冷灰、萤夜深蓝、雪天奶灰、蓝调暮色、极夜极光；冰面反射同一套 `coldSkyColor`，并加入雪面闪光层。
- 冰湖改为不规则湖岸，增加雪岸、冰压力脊、干芦苇、倒木与树桩；草地被雪毯覆盖，只留霜草尖。
- 冰面增加积雪斑、冻入的枯枝、气泡和蜿蜒的开放水面；冻结溪流中保留一段流动水带，火堆在冰面留下暖色反光；冰缘增加浅色厚度带。
- 雪毯加入风吹雪纹 bump 和雪面 glitter，雪地不再是一整片纯白；离开冷色/雪景时会清除森林树叶上的残留积雪。
- 暖色窗光、火堆、极光和局部发光体进入半分辨率选择性辉光；不做全屏 bloom，避免雪地和天空整体泛白。
- 岛底增加缓慢流动的云海，冷色场景增加低角度暖阳、长阴影、雾气和轻微暗角。
- 极光由天空 shader 帘幕、3D 低透明帘幕和星空叠加；使用冷青下缘、绿色主体、蓝紫上缘，不使用粉色 hem。绿色与蓝紫方向光随极光呼吸照亮雪地、冰面和木屋。
- 冷色岛按需构建，首屏不生成隐藏岛；树木按 12 组变体共享几何原型，再通过尺度、朝向和叶色变化，减少同屏重复建模。
- 程序化树木骨架：针叶按枝轮生长，阔叶从主枝分叉，叶簇挂在枝端；原型保留高矮、偏冠、枯枝和苔藓方向，实例通过尺度与朝向变化。
- 坡面接地与接触阴影，配合草簇、花丛、灌木、蕨、倒木、蘑菇和落叶层；溪流增加河床、湿岸、水下卵石与溪石泡沫。
- 程序化材质微细节、PMREM 天空环境光、分层雾和重新平衡的日照 / 阴影，让低多边形表面不再像塑料。
- 水源改为岩缝涌泉，溪流沿岛屿边缘跌落成主瀑布；白天偶有鸟群掠过林梢。
- 晨光 / 午后 / 夜晚及晴朗 / 薄雾 / 小雨 / 雪景自由组合。
- 主画面为 Three.js 微缩悬浮岛屿，可拖拽旋转、右键 / 双指平移、滚轮朝光标缩放；单击树木唤起微光，点击地表触发互动，双击或探索胶囊进入细节。
- 六种风景合并为底部一个“风景”按钮：点击展开胶片式场景菜单，选择后收起，不再平铺六个标签。
- 雨雪效果在岛屿上方真实落下；雪景会积在树冠与地表，夜晚点亮萤火与溪流。雨天使用冷灰色调，薄雾由多层缓慢漂移的雾带组成，并随镜头产生视差。
- 山涧从林间涌泉出发，沿岛屿边缘跌落成主瀑布；水流、飞溅和涟漪随场景变化。
- 浏览器合成微风、鸟鸣、溪流、雨声、白噪音、粉红噪音、棕色噪音、炉火和潮声，各声部独立调整。
- 雨夜入睡、林间阅读、清晨醒神声音预设；支持保存、重命名与删除本地自定义混音。
- 15 / 30 / 45 / 60 分钟及自定义睡眠计时，结束前一分钟渐弱并停止播放，可暂停、继续或取消。
- 沉浸观察、PNG 明信片下载、拾光收藏及重访；支持记录心情备注、场景筛选、关键词搜索和 JSON 备份导入导出。
- 1 / 3 / 5 分钟呼吸练习，可随时结束。
- 手机适配、键盘操作及减少动态效果偏好。

## 项目结构

```text
src/
  App.vue                     页面与响应式状态
  main.js                     Vue 应用入口
  styles.css                  森林主题与响应式样式
  island.css                  岛屿页面布局
  assets/                     森林图片及生成提示词
  scene/                      程序化地形、树木、草花、水面、天气与材质
    terrain.js                岛屿、崖壁、石头的几何与高度场
    vegetation.js             树木骨架、枝轮、树冠与叶片
    flora.js                  草簇、花与花境
    leaves.js                 叶片与针叶几何
    water.js                  溪流、瀑布与水面着色
    weather.js                雨雪与飘落叶片
    vines.js                  垂挂藤蔓
    butterflies.js            蝴蝶几何与飞行
    birds.js                  偶发掠过的低模鸟群
    cabin.js                  欧洲原木小屋 / 极地科考小屋
    coldIsland.js             独立冷色岛、冰湖、冰川与场景切换
    coldMood.js               清晨 / 黄昏 / 夜晚 / 极地光照配方
    glacier.js                连续冰川墙、冰裂隙与冰塔
    aurora.js                 极光帘幕、星空与月光
    environment.js            程序化天空 IBL
    grounding.js              贴合地形的接触阴影
    understory.js             灌木、蕨、倒木、蘑菇与落叶层
  components/
    ForestDialog.vue          v-model 控制的原生对话框
    ForestIcon.vue            可复用 SVG 图标
    IconSprite.vue            图标符号集
  composables/
    useForestAudio.js         Web Audio 合成与资源释放
    useForestScene3D.js       Three.js 悬浮岛屿、雨雪天气与场景互动
    useSoundPresets.js        声音氛围预设与本地自定义混音
    useMomentJournal.js       收藏响应式状态与本地持久化
    useBreathing.js           呼吸节奏和计时器
    usePostcard.js            明信片生成与下载
  data/
    forest.js                 场景、天气和声音配置
public/favicon.svg
scripts/check.mjs
vite.config.js
```

界面使用 `v-for`、`v-if`、`v-model`、`@click`、`:class`、`:style` 等 Vue 模板语法；状态通过 `ref`、`reactive`、`computed` 和 `watch` 管理。Canvas、Web Audio 和下载操作使用原生浏览器 API，资源通过 Vue 生命周期清理。

森林图片由内置 ImageGen 工具生成，提示词见 `src/assets/image-prompt.txt`。Google Fonts 是可选字体请求，离线时回退到系统字体。音频为合成环境声，收藏只存储在 localStorage。
